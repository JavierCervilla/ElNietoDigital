# Marca — El Nieto Digital

Logo: un móvil sonriente. Dice "el móvil no muerde" sin explicarlo.

## Archivos
| Archivo | Uso |
|---|---|
| `marca-color.svg` | Símbolo solo, a color. Favicon, marca de agua, stickers |
| `marca-mono.svg` / `marca-negativo.svg` | Símbolo en un solo color (sobre claro / sobre oscuro) |
| `logo-horizontal-color.svg` (+ `.png`) | Logotipo principal: cabecera de web, cierre de vídeo, documentos |
| `logo-horizontal-mono.svg` / `-negativo.svg` | Versiones en un solo color |
| `logo-apilado-color.svg` (+ `.png`) | Versión vertical: portadas, tarjetas, formatos cuadrados |
| `perfil-1024.png` (+ `.svg`) | Foto de perfil para todas las redes (fondo naranja) |
| `perfil-1024-claro.svg` | Foto de perfil alternativa (fondo crema) |

Los textos están convertidos a trazados: los SVG se ven igual en cualquier ordenador aunque no tenga la fuente.

## Colores
- Naranja tostado (acento): `#C8461F`
- Azul marino (tinta): `#1F2A44`
- Crema (fondo): `#FBF7F0`

Contraste naranja sobre crema 4,5:1; azul sobre crema > 12:1. Aptos para lectores mayores.

## Tipografía
- Logotipo: Nunito ExtraBold (Google Fonts, gratuita).
- Texto de vídeos y miniaturas: Nunito o Atkinson Hyperlegible, siempre en tamaño grande.

## Reglas
- No deformar, no girar, no añadir sombras ni degradados.
- Sobre fotos, usar siempre la versión negativa dentro de una pastilla de color.
- Espacio libre alrededor: como mínimo la altura de la pantalla del móvil.
- Tamaño mínimo del símbolo: 24 px (favicon) — la sonrisa debe seguir viéndose.

## Editable
El logo y sus variantes (banner de YouTube, plantilla de miniatura, monocromo) están en el lienzo de diseño de Claude; desde ahí se exportan nuevas versiones.
