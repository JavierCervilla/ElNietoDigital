# Bitácora — construyendo El Nieto Digital en público

Aquí documento, semana a semana, cómo creo desde cero el canal y la comunidad.
Sirve para rendirme cuentas y para convertir el proceso en contenido para la comunidad técnica (LinkedIn), sin contaminar el feed dirigido a mayores.

## Cómo se usa
- Un archivo por semana: `bitacora/AAAA-semana-XX.md` (15 minutos el domingo).
- Se rellena la plantilla aunque la semana haya sido mala: las malas semanas son las más útiles.
- Lo publicable se adapta a un post; lo personal se queda aquí.

## Separación de audiencias
- Feed de El Nieto Digital: solo contenido útil para mayores. Nunca métricas ni "cómo crezco".
- LinkedIn / perfil profesional: el detrás de cámaras, aprendizajes, métricas.

## Reglas
- Sin apellidos, sin nombres de personas de la comunidad, sin datos de contacto.
- Métricas reales, sin redondear hacia arriba.
